— 02 · 已经能跑的东西

FORGE:线圈怎么摆,先让机器试

装置的第一个硬约束是线圈怎么摆。FORGE 把这件事做成了闭环:参数化线圈 → 算磁场 → 打分 → 入册 → 从册子里学规则。它不是演示,是 v0.1.0,已经跑完 12,001 次评估。

闭环
四条搜索路线(随机 / LHS / 进化 / 热启动进化)在同等预算下比较,全部写进同一个册子。
人机对比
机器最优 1.3814,人工基线 −0.2906(Δ = +1.672);四种方法在 3/3 个随机种子上都赢。
门禁
16 道验收门全绿(含跨语言复核:Go 求解器与独立 Python oracle 的场值一致到 2.2e−12)。
诚实的限制
那个最优解很可能不可造 —— 它把一圈线圈放在距打分点 4.2 mm 的位置,因为目标函数还没有导体净空约束。我们把这一条和数字一起公开。
