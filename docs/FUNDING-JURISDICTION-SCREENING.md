## 零 先接受一个前提:离岸主体不消除境内风险

需方口径(2026-09-22)原样记录:

> 境外主体并不会自动消除中国境内风险。如果团队、网站受众或宣传对象仍主要在中国境内,仍需评估中国监管影响;官方 2026 年通知明确禁止多类虚拟货币相关业务和宣传支持。

因此筛选必须**同时**回答两个问题:

1. **境外那一侧**:主体设在哪、能不能合法收钱、要交什么税、要做什么 AML/KYC;
2. **境内这一侧**:团队在哪、网站面向谁、宣传对象是谁、有没有构成"向境内公众传播吸收资金信息"或"为虚拟货币相关业务提供展示/宣传"。

工程侧纪律(已冻结):
- 服务器 / RPC / 合约 / 前端地理限制**都不能**"解决"法域问题;
- 法域未定 → 不写最终募资文案、不定主体名称、不部署收款合约、不公开任何地址;
- 首页只有「公开记录」区块(见 [`RECORDS-LAYER-PLAN.md`](./RECORDS-LAYER-PLAN.md))。

## 一 要先回答的 12 个问题(给律师的问题清单)

| # | 问题 | 为什么重要 |
|:--|:--|:--|
| 1 | 主体形式:公司 / 基金会 / 非营利 / 信托 / 其他? | 决定能否公开发起募资、税务待遇、披露义务 |
| 2 | 注册地与实际运营地分别在哪?(实际管理地在税收与监管上常被看重) | 两地不同会带来双重义务 |
| 3 | 性质是"捐赠"还是"科研赞助"?法律定义与后果不同 | 影响合同形式、收据、退款、捐赠人权利 |
| 4 | 是否需要 AML/KYC?门槛与义务范围? | 决定能不能收匿名/小额、能否用公链地址 |
| 5 | 是否允许接收加密资产(原生币 / 稳定币)? | 有些法域对加密收款接近禁止或需牌照 |
| 6 | 是否允许**向公众**募资?(还是只能向特定人/机构) | 直接决定"公开网页 + 收款地址"这条路能不能走 |
| 7 | 税务:收据怎么开、谁来开、捐赠人能否抵扣? | 影响对外承诺,承诺了做不到是法律风险 |
| 8 | 退款规则:法定/约定可否退款? | 链上不可逆与法定退款权的冲突必须提前处理 |
| 9 | 捐赠人所在国家的限制(美/欧/英/日等各自的规则) | 面向全球募集 ≠ 每国都合法 |
| 10 | **制裁与 PEP 筛查**义务:谁做、做到什么程度、留档多久? | 募资平台的合规底线;缺失会成为牌照/银行开户障碍 |
| 11 | 数据保护:募集过程收集的数据受哪套法管(GDPR 等)? | 决定表单能收什么、留多久 |
| 12 | 银行与支付:能不能开户、能不能收加密、渠道是否稳定? | 纸面合法但收不到钱/随时被关户 = 不可行 |

## 二 主体形式:先看"能不能公开募资",再谈税

| 形式 | 常见优点 | 常见代价 | 要问律师 |
|:--|:--|:--|:--|
| 有限公司(LLC/Ltd/GmbH 等) | 设立快、成本低;治理简单 | 通常**不能**向公众募集"捐赠"(没有公益资格);股权结构让"捐赠不产生权益"难以自证 | 能否以"科研赞助/服务"名义收款?需要什么文件? |
| 非营利/公益组织(基金会、协会) | 可合法接收捐赠、可开收据;公信力高 | 设立慢、章程约束多、披露与年审义务重;用途受限 | 公益目的如何表述才涵盖本项目的科研方向? |
| 基金会(独立法人的 Stiftung 型) | 长期治理稳定、可设理事会 | 设立成本与资本要求高;变更目的困难 | 能否给境外研究者拨款? |
| 信托 / 受托结构 | 财产隔离清晰 | 不一定是"募资主体";受托人义务重 | 谁对外签合同、谁开收据? |
| DAO 包装的法人(如基金会 + 链上治理) | 与链上治理叙事契合 | 法律上是"基金会",链上不是主体;**治理权 ≠ 法律责任** | 谁承担法律义务?链上投票能否被章程承认? |

**口径**:本项目已定「捐赠不产生股权、分红、回购权、收益权」(`DONATION-FREEZE.md` §五)—— 那么主体形式应当**天然支持**这一点(非营利/基金会通常比公司更贴合),这一条要优先于"设立便宜"。

## 六 与工程的关系(现在就该冻结的对应关系)

| 阶段二结论 | 工程侧动作 |
|:--|:--|
| 选定法域 + 主体 | 才能定主体名称、募资文案、收据形式 |
| 明确"允许接收加密资产 + 允许公众募资" | 才能设计收款合约的最终形态并进入阶段四审计 |
| 明确 AML/KYC 义务 | 收款合约**仍不收集个人信息**(链上不存 PII)—— KYC 若需要,只能发生在链下流程里;这一点会影响"能不能收公链地址" |
| 结论是"不能公开募资" | 收款部分整体删除,只保留 [`RECORDS-LAYER-PLAN.md`](./RECORDS-LAYER-PLAN.md) 的记录层 |
| 未定 | 首页只有记录层;`config.donate` 不启用;不部署、不公开地址 |
