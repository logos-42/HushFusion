# 控制引力场的代数系统

对应公开页 `docs.html`（第五页，导航「理论」）。内容源 `logos-42/Hibs-Physics`
仓库的 `GravityControl.lean`（GCA0–GCA7）与 `scripts/verify_gravity_control.py`。

## 结论

能不能根据现在推导出的物理学，设计一种控制引力场的代数系统？答案：**有，而且大有可能**。
但要先想清楚的不是怎么做出来，而是怎么解释、怎么使用。

**基本逻辑的基元不是真值，是起伏能量（非负二次型）。**

```
Φ = ½|C|²            —— 引力是空间场的泛函，加速度 = −∇Φ
Q_A(v) = Σ_{i∈A}(v_i − v̄_A)²   —— 逻辑基元；命题 p_A ⟺ Q_A = 0 ⟺ ∇Φ = 0 ⟺ 引力关闭
```

## 为什么基元是起伏能量（四条判据全命中）

1. 可观测量——一个标量，有限次测量可定
2. 幂等可判定——抹平两次 = 抹平一次（P²=P，控制是设定不是累加）
3. 二值退化——Q_A = 0 ⟺ A 内流动常值 ⟺ A 内 ∇Φ = 0 ⟺ 引力关闭
4. 代价共轭——抹平成本 ∝ 被拿走的起伏²，基元量本身就是代价（布尔真值没有价格）

## 推导链

```
二次型 →(极化恒等式) 内积 →(正交) 正交投影 →(投影族) 逻辑运算
布尔代数 = 全部投影可交换的子格
```

两个语义点：补元是**正交补 I−P**，不是集合补——「取消抹平」≠「制造反向引力」；
μ=1（质量取消、随流 dτ=0）与 ∇Φ=0（势平坦）是两条不同通道，别混。

## 布尔性边界（被数值推翻过一次）

**可交换 ⟺ 控制区域族层状（两两不交，或一个包含另一个）。**

- 不交（GCA6a）⟹ 可交换
- 嵌套（GCA6b，吸收律 P_A∘P_B = P_A）⟹ 可交换（最初误写为「不可交换」，数值扫描推翻）
- 部分重叠（GCA6c）⟹ 不可交换 ⟹ 分配律失效 ⟹ 非布尔

工程规则：区域层状 ⟹ 控制程序可像布尔式化简综合；部分重叠 ⟹ 控制词变有序词，
执行次序进入语义。这是装置几何的设计原则，不是事后检查。

## 锁定 = 交换子不为零

FC5 / FC10 / TM2 三条锁定定理是同一个代数事实的多个指纹——对应控制通道不可交换。
锁定 = 缺一个独立（可交换）通道；解法 = 加一个作用在不相交自由度上的通道。

| 定理 | 表达式 | 锁定了什么 |
|------|--------|-----------|
| FC5  | S*(μ)/S*(0) = τ_E(μ)/τ_E(0) = 1/√(1−μ) | 两个量被同一个 μ 按同一函数锁死 |
| FC10 | Θ = B²/m_eff | B² 和 m_eff 被 μ 反着锁 |
| TM2  | m_eff² = s²(1−μ)² | μ 不到 1 就必有质量 |

## 三个类比

1. **刷墙**：两块墙不挨着 / 大包小 / 部分重叠 ⟹ 先后无所谓 / 吸收 / 顺序进入语义。
2. **开关 vs 调光旋钮**：布尔是 0/1 开关；引力控制是「设定到目标值」的旋钮，幂等但带代价。
3. **一个旋钮管亮度 + 色温**：单旋钮只能画一条线；要独立控制两个量，加第二个不打架的旋钮。

## 诚实边界

全部定理 = 代数恒等 + 序关系 + 有限维见证（真但平凡）；「抹平 = 引力关闭」属解释层
（与弱场 GR 数值不可区分，且只关区域内部、边界跳变保留）；基元选择由四条判据支撑
而非公理推出；μ 主动产生仍是第二输入缺口；无新物理预言。
