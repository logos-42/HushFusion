## 四 分辨率纪律(最容易踩的坑)

| 等级 | 素材宽度 | 允许的最大显示宽度 |
|:--|:--|:--|
| 可放大到约 1.3× | 500–1312px | 版面列宽 |
| 接近原生(1–1.15×) | 242–304px | ≈ 原生像素 |
| 只允许缩小 | 60–168px | 原生或更小 |

**规则:一块素材永远不许被放大来填版面。** 放大不会变清晰,只会变糊。
本项目里已经为此做过两处修正:

* `ui/mockup-mobile.png`(242px)曾从「拉满半栏」收到 242px 上限 —— 这两块(以及 `news/news-0x`)
  后来由需方确认多余,整块退役,对应版式规则也已从 `style.css` 删除;
* 现在页面上需要守这条纪律的只剩 `art/plasma-ring.png`(295×124,按原生尺寸用)。

## 五 切图建议(下次切图/重做时照这个做)

### 5.1 选底:先判断素材「长在什么底上」

```text
深色笔迹 + 纸底   → 保留纸底,当「纸块」用(键出透明会在笔迹周围留灰晕)
白色笔迹 + 深色底 → 键出为透明,得到干净的纯白图形(本项目 --white 版本)
纯色图标(自带底) → 原样切,不要抠
```

### 5.2 裁剪

```text
· 先做投影分析找边界(行/列亮度突变),再人工目视核对 —— 不要只靠眼睛估坐标
· 文字类留 5–8px 安全边(本项目 logo-corner 与 tagline-en 第一版都切掉过末字符)
· 图标的圆角砖/圆章类,把外部砖底一起切进来(它是设计的一部分)
· 每个切片都记录源图裁剪框,写进 manifest —— 否则半年后没人知道它从哪来
```

### 5.3 交付

```text
· PNG 无损;不放 SVG(源是位图,描摹等于臆造)
· 切完做一张 contact sheet 叠在**目标底色**上(本项目是深蓝黑)再看一遍:
  白底预览看不出「在深底上的白字消失」这类问题
· 输出 sha256;素材包与页面引用必须能对上
```

## 七 点缀素材池:`assets/cover/`(来自 bolloon 项目)

```text
来源      ~/Downloads/bolloon-UI/fig/            (80 张 512×682 JPEG,高清版)
清单      ~/Downloads/bolloon/src/web/covers/index.json  (同一批文件名,Web 压缩版索引)
导入      python3 tools/import_covers.py         (原样复制,不重编码)
登记      assets/cover/manifest.json             (文件名 / 尺寸 / 字节 / sha256 / 原路径)
```

**内容**:80 张竖构图(512×682)封面,一张一个**笔触字形**——单色笔迹落在浅底上,
配色以绿 / 橙 / 蓝 / 粉为主,少数为深底亮笔迹。它们与主素材(手绘海报)**同源的手绘气质**,
所以适合当点缀,不适合当主视觉。

### 7.1 使用纪律(用了就不能破坏现有设计线)

```text
· 每页最多 1–2 张,只做**小尺寸点缀**(建议宽 ≤ 140px)
· 它们是**亮底**素材:直接摆在深底上会变成一个发光的白方块(观感像贴纸)
  → 三选一:①放进 .paper-chip 纸块里 ②加 1px 发丝线边框并压到 60% 不透明度
            ③与纸色一起作为「印章」组合(小方块 + 等宽编号)
· 不许放大(原生 512×682,缩小可用;放到整屏宽会糊且抢主素材)
· 不许改色/裁剪构图:**它是作品,不是背景纹理**
· 每页之间避开同色碰撞(它们配色很多,选之前先看图)
```
