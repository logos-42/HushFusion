## 一 任务重述

为 **HUSHFUSION(消音计划)** 构建一个**深色、展览式、零构建**的静态品牌站:

0. **口径(需方指定,2026-09-17 升格)**:本计划的**技术逻辑是反引力场**;近期产出是**没有噪音的能源、无限能源,
   以及安静无声的动力源**;**核心动机**是**可以控制引力场的飞行器与交通设施**;**终局愿景**是**物质质量归零后的引力场相变**。
   「消音计划」降为**第一阶段**的命名(阶段性),消音仍可出现但不占主要篇幅;**愿景必须出现在序页**。
   因此「降噪」只能当「要拿到的东西」写,不能当技术写;技术栏 01 沿用海报原词 `Time-Varying Gravitational Field`,不做机制展开
   (源素材里没有),只作为口径句出现。详见 `docs/design-brief.md` §〇。
1. **素材是最高优先级**:整站的取色、字重对比、留白与节奏,全部从一张手绘海报反推;素材的构图与颜色不被修改。
2. **只用一支强调色**:品牌蓝。琥珀色只允许出现在「状态点」一处。
3. **禁止模板件**:不做 hero 大横幅 + 大按钮、不做三列卡片栅格、不做大圆角卡片、不做阴影堆叠、不做装饰性渐变。
4. **零构建**:纯 HTML + 一个 `style.css` + 一个 `app.js`,无 npm、无打包器、无框架。
5. **可验收**:每一页都能用真浏览器脚本断言(见 §11),而不是靠肉眼看。

> 已交付实现:**单页** `index.html` + `style.css` + `app.js`。
> 页面数由需方 2026-09-17 从 6 收到 4:`technology` 并入 `progress`、`join` 并入 `hibs`、`team` 改名为 `hibs`;已删除的三页内容没有丢,去处在 §7 逐页布局里写明。
> 本文档描述的就是这一版实现;凡本文档与实现不一致处,**以本文档为准并修实现**。

### 2.1 素材分辨率纪律(重要)

源图是从设计板截图重编码而来的,**同一个元素在不同位置的可用分辨率差别很大**:

| 分辨率等级 | 素材 | 允许的最大显示宽度 |
|:--|:--|:--|
| 可放大到 1.3× 以内 | `poster-full`(1312)、`art-tokamak`(792)、`art-tokamak-wide`(756) | 版面列宽即可 |
| 接近原生 | `plasma-ring`(295)、`slogan-cn`(262)、`list-frc`(160) | **≈ 原生像素** |
| 只能缩小 | `mark-bolt--white`(76)、`tile-vortex`(95)、`app-icon`(106) | 原生像素或更小 |

**规则**:一块素材**永远不许被放大来填版面**。放大不会变清晰,只会变糊;
需要更大尺寸时应当**重新出图**(见 §10 重绘清单),而不是拉伸 CSS。

## 三 色系合成(骨 + 一支强调色)

### 3.1 骨:一个深底 + 三个面

| 令牌 | 值 | 来源 | 用在哪 |
|:--|:--|:--|:--|
| `--bg` | `#080F1A` | 设计板印的深色底 hex | 全站背景 |
| `--bg-2` | `#0C1626` | 由 `--bg` 提亮一档 | 命令板/标签框的上半 |
| `--bg-3` | `#111E33` | 再提亮一档 | 命令板下半、下拉菜单 |
| `--bg-hover` | `#16263F` | 再提亮一档 | 下拉项 hover |

层级靠**背景面 + 1px 发丝线**,不靠阴影。全站唯一的阴影是顶栏下拉(`box-shadow: 0 24px 60px rgba(0,0,0,.5)`),因为它必须浮在内容之上。

### 3.2 文字三级

| 令牌 | 值 | 对 `#080F1A` 对比度 | 用途 |
|:--|:--|--:|:--|
| `--ink` | `#F8FAFC` | 16.3:1 | 标题、正文重点 |
| `--ink-2` | `#9CA3AF` | 7.6:1 | 次级正文、导语 |
| `--ink-3` | `#7C8CA3` | **5.6:1** | 元数据、图注、日期(过 WCAG AA) |

> **注意**:设计板上的灰 `#9CA3AF` 直接当第三级太浅,3.5:1 不达 AA。
> 所以第三级由 `#9CA3AF` 派生为 `#7C8CA3`,这是**对素材色的一次有记录的偏离**。

### 3.3 唯一强调色

| 令牌 | 值 | 说明 |
|:--|:--|:--|
| `--accent` | `#3B82F6` | **设计板上印的品牌蓝 hex**,作为规范值 |
| `--accent-hover` | `#60A5FA` | hover 提亮 |
| `--accent-deep` | `#1D4ED8` | 备用的深色版 |
| `--accent-glow` | `rgba(59,130,246,.25)` | 焦点环 / 1px 描边光晕 |

> 实测:海报上色卡圆心是 `#276DFD`(更亮、更饱和),设计板印刷码是 `#3B82F6`。
> **规范用印刷码**,理由是品牌方已把 `#3B82F6` 写在设计板上;
> 若要更贴近海报笔触,整体替换 `--accent` 一处即可(这是唯一需要改的地方)。

**强调色的允许用途(白名单)**:链接、`is-active` 态、序号、kicker、命令提示符、焦点环、`See all`。
**禁止**:用于标题正文、用于大面积填充(唯一例外是实心小块,文字取底色)。

### 3.4 唯一的语义色(琥珀)+ 纸色

| 令牌 | 值 | 约束 |
|:--|:--|:--|
| `--amber` | `#F59E0B` | **只允许出现在 `.status` 状态点一处**(表示「进行中」)。它不构成第二强调色 |
| `--paper` | `#F8EADA` | 海报纸色**实测值**。只用于极小面积反白块(如纸块上的标语),不铺大面积 |

## 四 字体与字号阶梯

### 4.1 三件套(角色固定)——本项目的一次有理由的偏离

| 角色 | 字体栈 | 理由 |
|:--|:--|:--|
| 展示 / 标题 | `-apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans SC", …` | 品牌是**几何无衬线 + 手绘笔迹**;衬线标题会与手绘笔迹互相打架 |
| 正文 / 说明 | 同上(300 字重) | 长文可读 |
| 元数据 / 代码 | `ui-monospace, "SF Mono", "JetBrains Mono", Menlo, monospace` | 序号、日期、命令、标签 |

> **关键决定**:通用做法里「展示级用衬线」在这里被放弃,风格角色交给真实素材与版式。
> **2026-09-17 修订(需方要求)**:页面上不再出现任何「字体图片」—— 序厅原来的手写体主标
> `wordmark-brush.png`(503×123 纸底位图)已撤下,`<h1>` 回到**文字渲染**;顶栏字标同样只用文字
> (原图仅 102×19,2× 屏会糊)。手绘感现在只由海报原件承担,不靠字体、也不靠字标图片。

### 4.2 字号阶梯(实现中的真实值)

```text
kicker          12px mono, letter-spacing 3px, uppercase
展示级标题      clamp(2rem, 5vw, 3.6rem)  字重 300, line-height 1.08
section 标题    clamp(1.6rem, 3.4vw, 2.6rem)
列表项标题      clamp(1.15rem, 2.4vw, 1.7rem)
导语 / lede     1.05rem, max-width 42em
正文            16px / line-height 1.7 / 字重 300
序号            13px mono, letter-spacing 2px
命令 / 代码     .86rem mono
元数据 / 图注   11–12px mono, letter-spacing 1px
```

**排列纪律**:层次来自「3.6rem 标题 vs 12px 元数据」的**对比**;
不要把它们拉到中间(三级字号并排 = 模板味)。

### 4.3 间距体系

```text
区块内边距   padding: clamp(60px, 10vh, 130px) clamp(24px, 6vw, 80px)
版心         max-width: 1200px; margin: 0 auto
栅格间距     gap: clamp(20px, 4vw, 52px)
行高         body 1.7;标题 1.15
圆角         --r: 3px(全站唯一圆角值)
```

## 六 组件结构(与 `style.css` 类名一一对应)

| 组件 | 类名 | 结构要点 | 反模式 |
|:--|:--|:--|:--|
| 顶栏 | `.topnav > .masthead` | 三段均布:品牌左 / 导航中(`flex:1` + 居中)/ 元信息右;`position: sticky` + 半透明 + `backdrop-filter: blur(10px)` | 导航小字挤在右上是「未完成的草稿」相 |

| 展品 | `.exhibit` | 图 + 发丝线图注条(文件名 / 尺寸 / 来源) | 加边框光晕、加悬停缩放 |
| 命令板 | `.cmd-plate` | `background: linear-gradient(180deg, bg-2, bg-3)` 是**全站唯一允许的渐变**,用来让面板微微浮起替代阴影;hover 只加 1px 强调色描边光晕,不位移不缩放 | 悬停位移/缩放 |
| 标签框 | `.tabs-box > .tabs > .tab` + `.pane` | 标签 = 等宽序号 + 名称;面板首行 `.pane-tag` 放英文全称,下面用 `.spec-list`(dt/dd 两列 + 发丝线)承载「关心什么 / 难点」 | `.tabs` 必须 `flex-wrap: wrap` + 子项 `min-width: 0; white-space: nowrap` | 不加 `flex-wrap` → 最后一个 tab 被整条裁掉 |
| 文档表格 | `.table-wrap > table.doc` | 表头小号等宽大写;只留行底发丝线;`border-collapse: collapse` | 斑马纹 + 外边框 + 圆角 |
| 状态点 | `.status` | 琥珀点 + 大写等宽标签;**琥珀的唯一落点** | 拿琥珀当第二强调色刷一片 |
| 占位块 | `.placeholder` | 虚线框 + 等宽字,显式写「待填 + 需要谁提供」 | 编造内容填满版面 |
| 页脚 | `.foot` | **一行**等宽元数据;不做四列链接 + 社交图标、不写版本号 | 通用 footer |

派生文件用**双横线后缀**区分:`xxx--white.png` = 深色底键出为透明的版本。

### 10.2 切图纪律(踩过的坑)

1. **纸底键出会留晕,深色底键出才干净**。
   海报是「深色笔迹 + 有渐变的纸底」,把纸当背景色键出会在笔迹周围留下一圈灰晕;
   深色底上的白笔迹则相反,键出后是干净的纯白图形。
   → 结论:海报系的笔迹素材**保留纸底**当「纸块」使用;深色系的标志**键出为透明**。
2. **裁剪必须留 5–8px 安全边**,否则手写体的收笔会被切掉(本案第一版就把海报角标与英文角标的末字符切掉了,已修;
   这两块目前属于备用素材,见 `EXTRA_CROPS`)。
3. **低分辨率素材不放大**(见 §2.1)。
4. **每次改切图后重算 sha256**:`python3 tools/slice_assets.py` 会重写 `assets/manifest.json`。

## 十三 反模式清单(不要做的事)

```text
· 把低分辨率素材拉大填版面            → 只会变糊,应当重新出图
```

```bash

q = im.quantize(colors=10).convert('RGB'); c = Counter(q.getdata())
print([('#'+''.join(f'{v:02X}' for v in k), round(n/sum(c.values())*100, 1)) for k, n in c.most_common(4)])
PY
# → #1A3702 17.1% · #F0F0F0 16.3% · #F2F2F2 14.8% · #F1F1F1 12.7%
```
